# Тренажёр английского

Тренажёр перевода «русское предложение → английский» на основе открытой базы предложений [Tatoeba](https://tatoeba.org/ru).

Вам показывается русское предложение из Tatoeba — нужно написать его английский перевод и свериться с оригиналом (включая произношение носителя). Всё работает прямо в браузере, без аккаунтов и отправки ваших ответов на сервер.

**Живой сайт:** <https://ru2eng.github.io/> · **Руководство пользователя:** [guide.html](guide.html)

## Возможности

- **Настоящие предложения и аудио** — данные из Tatoeba: подбор по введённому слову, предложения с русским переводом и записями носителей.
- **Проверка ответа** — сравнение с оригиналом (регистр и пунктуация не учитываются) + локальная проверка грамматики через **harper.js** (работает в браузере, текст никуда не отправляется, после первой загрузки доступна офлайн).
- **Произношение** — повторное прослушивание записи носителя и запись собственного варианта с микрофона для сравнения.
- **Офлайн (PWA)** — приложение устанавливается на телефон/компьютер; страницы и уже использованные данные доступны без интернета. Кнопка «Скачать все данные» на странице настроек загружает весь набор сразу (~318 файлов, ~140 МБ) — после установки запускается автоматически, прерванную загрузку можно докачать.
- **Три темы оформления** — авто/тёмная/светлая, выбор сохраняется локально.
- **Ленивая загрузка данных** — поиск качает только нужные чанки (индекс по первой букве запроса + 1–3 пакета предложений).

## Как заниматься

1. Введите английское слово или словосочетание (например, *hello*) и нажмите **Найти**.
2. Вам дано русское предложение — напишите его английский перевод и нажмите **Проверить**.
3. Сравните свой вариант с оригиналом и прослушайте произношение носителя.
4. **Следующее предложение** — продолжить по слову, **Новое слово** — начать заново.

Если ответ отличается, но грамматических ошибок нет, он помечается как «рядышком»; при ошибках грамматики ваш вариант подсвечивается красным — клик по нему покажет список ошибок с вариантами исправлений.

## Локальный запуск

Требуется Python (или Node):

```bat
start.bat        :: поднимет http.server на http://localhost:8000 и откроет браузер
```

Без `start.bat`:

```bash
python -m http.server 8000
# или альтернатива: npx serve
```

Приложение требует HTTP/HTTPS (Service Worker и запись с микрофона не работают через `file://`).

## Установка как приложение (PWA)

- **Компьютер (Chrome/Edge):** значок «Установить» в адресной строке.
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone/iPad (Safari):** «Поделиться» ⎙ → «На экран "Домой"».

После установки офлайн-данные скачиваются автоматически (или нажмите «Скачать все данные» на странице настроек).

## Публикация

Статический сайт; публикуется через GitHub Pages простым push:

```bash
git push origin main
```

Репозиторий `ru2eng/ru2eng.github.io` — GitHub Pages раздаёт файлы как есть (текстовые данные автоматически отдаются с gzip). Лимит Pages — 100 МБ на файл, самые большие чанки (~9 МБ) далеки от него.

## Структура репозитория

```
├── index.html            # основной тренажёр (SPA)
├── settings.html         # страница настроек (тема, офлайн-предзагрузка)
├── guide.html            # руководство пользователя
├── app.js                # логика тренажёра
├── dl.js                 # офлайн-предзагрузка данных
├── theme.js              # переключение темы
├── styles.css            # стили (светлая/тёмная темы)
├── sw.js                 # service worker (кеш страниц + данных)
├── manifest.webmanifest  # PWA-манифест
├── start.bat             # локальный запуск (Python http.server)
├── tools/build_index.py  # сборщик данных data/
├── data/                 # сгенерированные данные (коммитятся)
│   ├── manifest.json     # версия, размер бакета, списки чанков
│   ├── widx/widx_<c>.json    # индекс по первой букве токена
│   ├── packs/pack_<b>.json   # предложения: текст, аудио, переводы
│   └── ru/ru_<b>.jsonl       # русские предложения
├── vendor/harper/        # локальный проверщик грамматики (WASM)
└── icons/                # иконки PWA
```

## Данные

- Источник: дампы Tatoeba — `https://downloads.tatoeba.org/exports/per_language/`.
- Пересборка данных: `python tools/build_index.py` (опции — `--help` или [DEVELOPER.md](DEVELOPER.md)).
- Данные разбиты на чанки: один файл инвертированного индекса на первую букву + пакеты по ~100 000 id предложений. Каталог `data/` хранится в репозитории (~140 МБ).
- **Атрибуция:** предложения и аудиозаписи — проект [Tatoeba](https://tatoeba.org/ru); аудиозаписи распространяются по лицензии **CC BY** авторов записей.

## Технологии

Чистый vanilla JavaScript (ES6+), без сборки и зависимостей; Service Worker для офлайн-режима; harper.js (WASM) для проверки грамматики. Грамматика, тема и скачанные данные хранятся локально — на устройстве пользователя.

Подробности для разработчиков: [DEVELOPER.md](DEVELOPER.md).
