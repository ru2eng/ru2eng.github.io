Оформление

Тема переключается по кругу: авто → тёмная → светлая. Выбор сохраняется на этом устройстве.

Данные для офлайн-режима

Обычно приложение скачивает данные по частям, по мере использования. Чтобы оно целиком работало без интернета (в том числе сразу после установки), нажмите кнопку ниже — загрузятся все файлы (~318 шт.). Прерванную загрузку можно продолжить, вернувшись сюда позже.
